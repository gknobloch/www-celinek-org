Tensions surfaced

T1 · display-underuse

The signature script is used exactly once

Sacramento — a distinctive flowing script and the brand's one moment of personality in type — is confined to the hero tagline. Everywhere else, one rounded sans (Comfortaa) does both headings and body, so the page reads as a single flat voice with a decorative flourish stapled on top.

Fix → give the script a defined, repeatable role (section openers / pull-quotes) so it becomes structural voice, not a one-off.

T2 · photo-underscale

One excellent photo, shown once, cropped to a band

The identity portrait is the strongest trust asset on the page, yet it lives in a single wide hero band and photography never returns — the rest of the page is text on cream. The asset is under-shared relative to its quality (2000w source).

Fix → let the portrait breathe at editorial scale and reuse photography (or portrait crops) in the concept / process / testimonial sections.

T3 · text-wall

Reassurance copy is delivered as paragraph walls

The gold "Pourquoi faire appel à une coach en rangement ?" band is a dense block of prose; "Comment ça se passe ?" is a genuine 3-step method (Faire connaissance → Envisager → Désencombrer) rendered as running paragraphs rather than a legible numbered sequence.

Fix → break the "why" into scannable value points; render the "how" as an explicit numbered 3-step process.

T4 · h1-semantics

The H1 is a decorative script string with broken spacing

The captured H1 text is "Lerangementauservicedevotrebien-être!" — spaces collapse in the script rendering, which is poor for SEO and screen readers, and the page's true value proposition ("Home organiser in the Haut-Rhin") is not the primary heading.

Fix → keep the script visual but back it with a properly spaced, semantically meaningful H1; make the who/what/where legible to machines.

T5 · proof-buried

Social proof is one quote, behind arrows, at the very bottom

"Ils m'ont fait confiance" holds a single testimonial in a carousel at the foot of the page — the strongest conversion lever (an emotional, specific client story) is the last thing seen and mostly hidden.

Fix → surface testimonial evidence higher and show more than one at a time.

T6 · accent-reserved

The vivid gold never helps the CTA

The high-energy gold #eed366 is spent entirely on link-hover states, while primary CTAs ("En savoir plus", "Contactez-moi") sit in muted sage. The one color that could pull the eye toward conversion is invisible until you already hover a link.

Fix → promote gold to the primary conversion CTA so the contact action is the brightest thing on the page.
